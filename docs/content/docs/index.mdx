## ts-kizuna is a spec-driven REST framework for TypeScript.

Declare your API once. What serves it and what calls it both come from that one config.

<GeneratedSurfaces />

It mounts onto the HTTP framework you already use, so Express, Fastify, Hono and Next.js keep serving your app exactly as they do now.
