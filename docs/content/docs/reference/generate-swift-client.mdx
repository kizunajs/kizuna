---
title: generateSwiftClient
description: Generate a native Swift client from a ts-kizuna API with URLSession and Codable.
---

Generate a native Swift client from your routes, built on `URLSession` and `Codable`.

<InstallTabs packageName="@ts-kizuna/swift" />

```ts
import { generateSwiftClient } from '@ts-kizuna/swift';
```

## Parameters

```ts
generateSwiftClient(api: ApiDefinition, config: SwiftConfig): string
```

| Parameter | Type            | Description                                                    |
| --------- | --------------- | -------------------------------------------------------------- |
| `api`     | `ApiDefinition` | The `api` from [`defineConfig`](/docs/reference/define-config) |
| `config`  | `SwiftConfig`   | Generation configuration                                       |

## `SwiftConfig`

| Option                | Type      | Required | Description                                                                                                           |
| --------------------- | --------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `namespaceName`       | `string`  | Yes      | Name for the generated Swift enum and client type (e.g. `'API'`)                                                      |
| `camelCaseProperties` | `boolean` | No       | Convert wire field names to camelCase properties, mapped back via `CodingKeys`. Default `false`                       |
| `unknownEnumCase`     | `boolean` | No       | Emit enums with an `unknown(String)` fallback so unrecognised wire values decode instead of throwing. Default `false` |

## Example

```ts title="generate-swift-client.ts"
import { writeFileSync } from 'node:fs';
import { generateSwiftClient } from '@ts-kizuna/swift';
import kizuna from '../kizuna.config';

const source = generateSwiftClient(kizuna.api, {
    namespaceName: 'API',
});

writeFileSync('generated/API.swift', source);
```

See the [Swift client guide](/docs/clients/swift) for CLI usage and integration patterns.
