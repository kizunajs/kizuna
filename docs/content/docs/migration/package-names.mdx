---
title: Package names
description: Moving from @ts-kizuna/* to kizunajs and @kizunajs/*.
---

Kizuna publishes under `kizunajs` from 2.0. Core dropped its scope, so it installs as `kizunajs`, and every other package moved from `@ts-kizuna/*` to `@kizunajs/*`. The 1.x packages are deprecated on npm and stop receiving fixes.

## What moved

| 1.x                         | 2.0                        |
| --------------------------- | -------------------------- |
| `@ts-kizuna/core`           | `kizunajs`                 |
| `@ts-kizuna/cli`            | `@kizunajs/cli`            |
| `@ts-kizuna/eslint-plugin`  | `@kizunajs/eslint-plugin`  |
| `@ts-kizuna/express`        | `@kizunajs/express`        |
| `@ts-kizuna/fastify`        | `@kizunajs/fastify`        |
| `@ts-kizuna/fetch`          | `@kizunajs/fetch`          |
| `@ts-kizuna/hono`           | `@kizunajs/hono`           |
| `@ts-kizuna/kotlin`         | `@kizunajs/kotlin`         |
| `@ts-kizuna/mcp`            | `@kizunajs/mcp`            |
| `@ts-kizuna/next`           | `@kizunajs/next`           |
| `@ts-kizuna/openapi`        | `@kizunajs/openapi`        |
| `@ts-kizuna/swift`          | `@kizunajs/swift`          |
| `@ts-kizuna/tanstack-query` | `@kizunajs/tanstack-query` |

## Imports

Core and its subpaths lose the scope:

```ts
import { k } from 'kizunajs';
import { ProblemDetailsSchema } from 'kizunajs/schemas';
import { createAdapter } from 'kizunajs/adapter';
```

Everything else keeps the shape it had, with the new scope:

```ts
import { mount } from '@kizunajs/express';
```

## The ESLint rule

The plugin registers under `@kizunajs`, so a rule you named in your config is renamed with it:

```js title="eslint.config.js"
export default [
    kizuna.configs.recommended,
    {
        rules: {
            '@kizunajs/no-unsupported-schema': 'off',
        },
    },
];
```

## The standalone generators

The Swift and Kotlin binaries drop the prefix:

```bash
kizuna-swift generate --config kizuna.config.ts --output ios/MyApp/Generated/APIClient.swift --namespace-name API
kizuna-kotlin generate --config kizuna.config.ts --out android/app/src/main/kotlin/com/example/APIClient.kt --namespace-name API --package com.example
```

## Regenerate your clients

A generated client imports the runtime package by name, so the file on disk still points at `@ts-kizuna/fetch` until you write it again:

```bash
kizuna generate
```

Run [`kizuna generate --check`](/docs/cli#kizuna-generate) in CI to catch a client that was left behind.
