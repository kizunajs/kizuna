## Requiring a review

```ts title="src/app/investor-relations/content.ts"
export default definePage({
    name: 'investorRelationsPage',
    requireReview: true,
    fields: [
        // ...
    ],
});
```

Publishing waits for an approval from someone other than the person who changed it. Anyone with a role under `reviews.roles` may approve without being asked. The rule holds in the routes, so the model gets the same answer.

## Several pages at once

The Publish dialog lists every page with changes. Tick the ones to publish, or ask for one review of all of them.

## People

The editor shows people by name and picture. `people.list` reads them from your own users:

```ts title="kizuna.cms.config.ts"
auth: {
    identity: 'editor',
    people: {
        list: async () => {
            const editors = await db
                .select()
                .from(users)
                .where(inArray(users.role, ['editor', 'admin']));
            return editors.map((editor) => ({
                id: editor.email,
                name: editor.name,
                image: editor.image ?? undefined,
                roles: [editor.role],
            }));
        },
        imageOrigins: ['https://lh3.googleusercontent.com'],
    },
},
```

## Owners

A page, global or item can have an owner. The editor shows them beside the page name, and the owner is suggested first for a review.

> Make Kari the owner of the investor pages.

## Sending the request

```ts title="kizuna.cms.config.ts"
reviews: {
    onReviewRequested: async ({ documents, reviewers, requestedBy, note }, { plugins }) => {
        await plugins.resend.sendEmail({
            to: reviewers.map((reviewer) => reviewer.email),
            subject: `${requestedBy.name} asked you to review ${documents.length} pages`,
            text: note ?? '',
        });
    },
},
```
