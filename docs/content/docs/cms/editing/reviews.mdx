<Tab value="Asking">

**Ask for review** sits in the `…` menu beside Publish. Pick one or more people, with the page's owner first and each person's role beside their name, and add a note for them. Send request waits until someone is picked:

<EditorFigure kind="ask" />

The status then reads "Waiting for review by Kari Nordmann". The reviewer sees the request in the editor, in their chat, and wherever you send it with `onReviewRequested`.

While it waits, **Withdraw request** takes it back, and the page reads as if nobody was asked.

</Tab>

<Tab value="Reviewing">

For the reviewer, **Review** sits beside Publish and opens the changes. Each change is listed under the tab it sits in, with what is live now beside the draft and the words added or removed marked. They **Approve**, or **Request changes** with a note for the person who asked:

<EditorFigure kind="review" />

Once it is approved, **Publish** sends it live. An approval covers the draft as it was, and a save after it marks the approval outdated. **Undo approval** takes it back while the draft is still unpublished, and the review waits for an answer again.

When changes are requested, the status says who asked for them, and their note sits at the top of the sidebar. **Ask Kari again** sends the draft back to them once it is fixed.

</Tab>

</Tabs>

## Comments on a field

**Comment** beside a change leaves a note on that one field. The person who asked sees it under the field on the Edit tab, and the reviewer sees it under the change. Either of them can comment, and **Resolve** folds a comment away once it is dealt with. Comments stay with the draft when Kari is asked again, and publishing clears them.

## Requiring a review

```ts title="src/app/investor-relations/content.ts"
export default definePage({
    name: 'investorRelationsPage',
    requireReview: true,
    fields: [
        // ...
    ],
});
```

Publishing waits for an approval from someone other than the person who changed it. Anyone with a role under `reviews.roles` may approve without being asked. The rule holds in the routes, so the model gets the same answer.

## Publishing past a review

Someone with a role under `reviews.roles` can publish before the approval comes. The Publish dialog shows them **Publish anyway** beside the reason Publish is waiting, and asks once more before it goes live:

```ts title="kizuna.cms.config.ts"
reviews: {
    roles: 'admin',
},
```

The publish route takes `{ force: true }` for the same thing. For anyone without one of those roles, `force` changes nothing and the route still answers `409`.

The review records that the draft was published past it, and by whom. Versions shows that version as "Published past review" with their name, so it is clear afterwards that nobody approved it.

## Several pages at once

The Publish dialog lists every page with changes. Tick the ones to publish, or ask for one review of all of them.

## People

The editor shows people by name and picture, and their roles where you pick reviewers. `people.list` reads them from your own users:

```ts title="kizuna.cms.config.ts"
auth: {
    identity: 'editor',
    people: {
        list: async () => {
            const editors = await db
                .select()
                .from(users)
                .where(inArray(users.role, ['editor', 'admin']));
            return editors.map((editor) => ({
                id: editor.email,
                name: editor.name,
                image: editor.image ?? undefined,
                roles: [editor.role],
            }));
        },
        imageOrigins: ['https://lh3.googleusercontent.com'],
    },
},
```

## Owners

A page, global or item can have an owner. The editor shows them beside the page name, and the owner is suggested first for a review.

## Sending the request

```ts title="kizuna.cms.config.ts"
reviews: {
    onReviewRequested: async ({ documents, reviewers, requestedBy, note }, { plugins }) => {
        await plugins.resend.sendEmail({
            to: reviewers.map((reviewer) => reviewer.email),
            subject: `${requestedBy.name} asked you to review ${documents.length} pages`,
            text: note ?? '',
        });
    },
},
```
