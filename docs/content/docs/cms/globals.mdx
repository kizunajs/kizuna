---
title: Globals
description: 'Content every page shows, like the footer, kept as one copy.'
---

Content every page shows, like a footer or the contact details, is a global. One copy serves the whole site:

```ts title="src/cms/content.ts"
import { z } from 'zod';
import { defineGlobal } from '@kizunajs/cms';

export const Settings = defineGlobal({
    name: 'settings',
    fields: [
        {
            name: 'footerText',
            schema: z.string().min(1).max(160),
        },
        {
            name: 'contactEmail',
            schema: z.email(),
        },
    ],
});
```

With [several sites](/docs/cms/sites), a global on `cms()` is shared, and every site shows the same copy. Listed under a site's `globals` instead, it belongs to that site.
