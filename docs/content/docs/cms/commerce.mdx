|                                           | Kizuna CMS                   | The engine                       |
| ----------------------------------------- | ---------------------------- | -------------------------------- |
| Copy, specs, media, categories, relations | Yes, with drafts             |                                  |
| Variants and SKUs                         | Declared here, SKU immutable |                                  |
| Price, stock, tax                         |                              | Yes, read live by the storefront |
| Cart, checkout, payment, orders           |                              | Yes                              |
| Pages, campaigns, search metadata         | Yes                          |                                  |

Kizuna never holds a price or a stock count. On publish it pushes product information to the engine, keyed by its own id, and the engine never writes back. The engine is Medusa here, and Shopify or your own routes work the same way.

## Products

```ts title="src/cms/content.ts"
export const ProductId = Kizuna.brand('ProductId', z.string());

export const Products = defineCollection({
    name: 'products',
    id: ProductId,
    fields: [
        {
            name: 'name',
            schema: z.string().max(80),
        },
        {
            name: 'slug',
            schema: z.string().max(80),
        },
        {
            name: 'category',
            schema: Categories.id,
        },
        {
            name: 'description',
            schema: RichTextSchema,
        },
        {
            name: 'specs',
            schema: z.object({
                weightKg: z.number().min(0),
                volumeLitres: z.number().min(0),
                material: z.string().max(60),
            }),
        },
        {
            name: 'variants',
            schema: z.array(
                z.object({
                    sku: z.string().max(40),
                    label: z.string().max(60),
                    options: z.record(z.string(), z.string()),
                })
            ),
            immutable: ['sku'],
        },
        {
            name: 'gallery',
            schema: z.array(ImageSchema).max(8),
        },
        {
            name: 'accessories',
            schema: z.array(ProductId),
        },
        {
            name: 'datasheets',
            schema: z.array(FileSchema),
        },
    ],
    indexes: ['slug', 'category'],
    on: {
        published: async (product, { plugins }) => {
            await plugins.medusa.upsertProduct(product);
        },
        deleted: async (product, { plugins }) => {
            await plugins.medusa.removeProduct(product.id);
        },
    },
});
```

A required field a product lacks is what `kizuna cms check` lists, so completeness is the schema. A SKU never changes once published.

## Pushing to the engine

The push is a plugin of yours, a few lines over Medusa's admin client. The product's kizuna id goes in `external_id`, which Medusa can look up by:

```ts title="src/plugins/medusa.ts"
export const medusaPlugin = definePlugin({
    slug: 'medusa',
    options: z.object({
        url: z.url(),
        token: z.string(),
    }),
    setup: ({ options }) => {
        const medusa = new Medusa({
            baseUrl: options.url,
            apiKey: options.token,
        });

        return {
            exports: {
                upsertProduct: async (product: Product) => {
                    const { products } = await medusa.admin.product.list({
                        external_id: product.id,
                    });
                    const body = {
                        title: product.name,
                        handle: product.slug,
                        external_id: product.id,
                        weight: product.specs.weightKg * 1000,
                        material: product.specs.material,
                        images: product.gallery.map((image) => ({
                            url: image.url,
                        })),
                        variants: product.variants.map((variant) => ({
                            title: variant.label,
                            sku: variant.sku,
                            options: variant.options,
                        })),
                    };
                    if (products[0] === undefined) {
                        await medusa.admin.product.create(body);
                    } else {
                        await medusa.admin.product.update(products[0].id, body);
                    }
                },
                removeProduct: async (id: string) => {
                    const { products } = await medusa.admin.product.list({
                        external_id: id,
                    });
                    if (products[0] !== undefined) await medusa.admin.product.delete(products[0].id);
                },
            },
        };
    },
});
```

Prices, stock locations and sales channels are set in Medusa, once per variant, by the people who own them. A product published before they are set is in Medusa and not for sale.

## The product page

Two reads by the same id. Content from the CMS, cached until the next publish. Price and stock from the engine, cached for seconds:

```ts title="src/app/products/[slug]/content.ts"
export default definePage({
    name: 'productPage',
    collection: Products,
});
```

```tsx title="src/app/products/[slug]/page.tsx"
export const generateMetadata = kizuna.content.pages.productPage.metadata;

export default async function ProductPage({ params }: { params: Promise<{ slug: string }> }) {
    const product = await kizuna.content.pages.productPage.get(await params);
    const live = await liveProduct(product.id);

    return (
        <main>
            <h1>{product.name}</h1>
            {live === undefined ? <p>Not available</p> : <Price variants={live.variants} />}
            <RichText value={product.description} />
            <Gallery images={product.gallery} />
            <Specs {...product.specs} />
            {live !== undefined && <AddToCart product={live} />}
        </main>
    );
}
```

```ts title="src/lib/live-product.ts"
export async function liveProduct(id: ProductId) {
    'use cache';
    cacheLife('seconds');
    const { products } = await medusa.store.product.list({
        external_id: id,
        fields: '*variants.calculated_price,+variants.inventory_quantity',
    });
    return products[0];
}
```

The cart and checkout talk to the engine from the browser, as in any Medusa storefront.

## Search

Index by product id: content from the CMS on `published`, a flat `minPrice` from the engine on its price events, merged with partial updates so a stock change touches one field.

## Storefronts per market

Storefronts are [sites](/docs/cms/sites). Products are shared on `cms()`, and a market adds its own copy and campaigns with `extendCollection`. One engine per market, or sales channels, is the engine's side.

## What editors change

Everything about a product except its price and stock, as drafts until published, and every page around it:

> Add the new oak desk from the supplier sheet, with three variants, and feature it on the front page.

## Without an engine

A small shop can be its own engine: a `carts` and an `orders` table behind routes that read prices from a `price` field on the product, and a Stripe PaymentIntent for the money. The product collection is the same.
