You declare what a page needs, beside the route that shows it:

```ts title="src/app/(front-page)/content.ts"
import { z } from 'zod';
import { definePage } from '@kizunajs/cms';
import { ImageSchema } from '@kizunajs/cms/schemas';

export default definePage({
    name: 'frontPage',
    fields: [
        {
            name: 'heading',
            schema: z.string().max(60).describe('Under 8 words. No full stop.'),
        },
        {
            name: 'intro',
            label: 'Introduction',
            schema: z.string().max(400),
        },
        {
            name: 'hero',
            schema: ImageSchema,
        },
    ],
});
```

The page reads it, typed:

```tsx title="src/app/(front-page)/page.tsx"
export default async function FrontPage() {
    const content = await kizuna.content.pages.frontPage.get();

    return (
        <main>
            <img src={content.hero.url} alt={content.hero.alt} />
            <h1>{content.heading}</h1>
            <p>{content.intro}</p>
        </main>
    );
}
```

Editors change it in their chat, or by clicking the page. Nothing goes live until someone publishes. The content lives in your Postgres.
