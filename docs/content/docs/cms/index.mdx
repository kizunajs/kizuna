</AlphaNotice>

<Supports items={['Next.js 16+', 'Postgres through Drizzle']} />

Editors change what the site says. You decide, in code beside each route, what they may change:

- **A page** has fields editors fill in, like a heading and an intro.
- **A global** shows on every page, like the footer.
- **A collection** holds many items of one kind, like articles.

The content lives in your database. Editors click text on the page to change it, and nothing goes live until they publish.

<InstallTabs packageName="@kizunajs/cms drizzle-orm" />

<Steps>

<Step>

## Create the tables

```sh
kizuna cms migrate --out drizzle
```

This writes the three `cms_` tables into your migrations folder. Run it with the rest.

</Step>

<Step>

## Declare a page

A `content.ts` beside the route lists what editors may change. Every field is plain Zod:

```ts title="src/app/(front-page)/content.ts"
import { z } from 'zod';
import { definePage } from '@kizunajs/cms';

export default definePage({
    name: 'frontPage',
    fields: [
        {
            name: 'heading',
            schema: z.string().max(60),
        },
        {
            name: 'intro',
            schema: z.string().max(400),
        },
    ],
});
```

</Step>

<Step>

## Let Next find the pages

```ts title="next.config.ts"
import { withKizunaCms } from '@kizunajs/cms/next/config';

export default withKizunaCms({});
```

It collects every `content.ts` into `src/cms.pages.ts` whenever Next starts or builds. Commit that file.

</Step>

<Step>

## Add the CMS to your config

```ts title="kizuna.config.ts"
import { defineConfig } from 'kizunajs';
import { nextAdapter } from '@kizunajs/next';
import { cms } from '@kizunajs/cms';
import { editor } from './src/identities';
import { pages } from './src/cms.pages';
import { db } from './src/db';

export default defineConfig({
    adapter: nextAdapter(),
    auth: {
        identities: {
            editor,
        },
    },
    content: cms({
        db,
        pages,
        auth: {
            identity: 'editor',
        },
        signInPath: '/login',
    }),
});
```

`editor` is the [identity](/docs/authentication) your editors sign in as, checked by your own sign-in. Mount the config once, and it serves everything the CMS needs, from the content to the images to draft mode:

```ts title="src/app/api/[...kizuna]/route.ts"
import kizuna from '@kizuna-config';

export const { GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS } = kizuna.api.mount({
    basePath: '/api',
});
```

`@kizuna-config` points at the config from anywhere, through `tsconfig.json`:

```json title="tsconfig.json"
{
    "compilerOptions": {
        "paths": {
            "@kizuna-config": ["./kizuna.config.ts"]
        }
    }
}
```

</Step>

<Step>

## Read it in the page

```tsx title="src/app/(front-page)/page.tsx"
import kizuna from '@kizuna-config';

export default async function FrontPage() {
    const content = await kizuna.content.pages.frontPage.get();

    return (
        <main>
            <h1>{content.heading}</h1>
            <p>{content.intro}</p>
        </main>
    );
}
```

`content` is typed from the page's fields. Until someone publishes the page, it answers 404.

</Step>

<Step>

## Add the preview

```tsx title="src/app/layout.tsx"
import { KizunaPreview } from '@kizunajs/cms/next';
import kizuna from '@kizuna-config';

<body>
    {children}
    <KizunaPreview content={kizuna.content} />
</body>;
```

Editors open `/api/draft`. Signed out, they go to `signInPath` first, and signed in, they land on the site in draft mode, where clicking any text edits it and the bar publishes.

</Step>
