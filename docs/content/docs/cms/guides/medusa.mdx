## The collection

A product is one item. Medusa writes the synced fields, and editors write the rest:

```ts title="src/cms/content.ts"
export const ProductId = Kizuna.brand('ProductId', z.string());

export const Products = defineCollection({
    name: 'products',
    id: ProductId,
    synced: {
        title: z.string(),
        handle: z.string(),
        thumbnail: z.url().optional(),
    },
    fields: [
        {
            name: 'description',
            schema: RichTextSchema,
        },
        {
            name: 'gallery',
            schema: z.array(ImageSchema).max(8),
        },
        {
            name: 'questions',
            schema: z.array(
                z.object({
                    question: z.string().max(120),
                    answer: z.string().max(600),
                })
            ),
        },
    ],
    indexes: ['handle'],
});
```

Synced fields show in the editor greyed, with "from Medusa". An item exists the moment Medusa sends it, so editors never create a product by hand.

## The sync

A Medusa subscriber upserts on every change and removes on delete, through the [content client](/docs/cms/api#a-client-for-readers) with the `sync` key:

```ts title="medusa/src/subscribers/product-sync.ts"
import type { SubscriberArgs, SubscriberConfig } from '@medusajs/framework';
import { cmsClient } from '../lib/cms-client';

export default async function productSync({ event, container }: SubscriberArgs<{ id: string }>) {
    if (event.name === 'product.deleted') {
        await cmsClient.sync.products.remove({
            params: {
                id: event.data.id,
            },
        });
        return;
    }

    const productService = container.resolve('product');
    const product = await productService.retrieveProduct(event.data.id);

    await cmsClient.sync.products.upsert({
        params: {
            id: product.id,
        },
        body: {
            title: product.title,
            handle: product.handle,
            thumbnail: product.thumbnail ?? undefined,
        },
    });
}

export const config: SubscriberConfig = {
    event: ['product.created', 'product.updated', 'product.deleted'],
};
```

`kizuna cms sync products` runs the same upsert over every product once, for the first import.

## The product page

```tsx title="src/app/products/[handle]/page.tsx"
export const generateMetadata = kizuna.content.pages.productPage.metadata;

export default async function ProductPage({ params }: { params: Promise<{ handle: string }> }) {
    const product = await kizuna.content.pages.productPage.get(await params);
    const { product: live } = await medusa.store.product.retrieve(product.id, {
        fields: '*variants.calculated_price',
    });

    return (
        <main>
            <h1>{product.title}</h1>
            <Price variants={live.variants} />
            <RichText value={product.description} />
            <Gallery images={product.gallery} />
            <AddToCart product={live} />
        </main>
    );
}
```

```ts title="src/app/products/[handle]/content.ts"
export default definePage({
    name: 'productPage',
    collection: Products,
    metadata: {
        title: ({ content }) => content.title,
        description: ({ content }) => content.questions[0]?.answer,
        image: ({ content }) => content.gallery[0],
    },
});
```

Price and stock are read from Medusa on every render. The cart and checkout talk to Medusa's Store API from the browser.

## Reviews

Customers write reviews, so they are records in your own table, through a route on the app API, listed by product id. Testimonials an editor picks for a campaign page are content.
