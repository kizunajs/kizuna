## Products

```ts title="src/cms/content.ts"
export const ProductId = Kizuna.brand('ProductId', z.string());

export const Products = defineCollection({
    name: 'products',
    id: ProductId,
    fields: [
        {
            name: 'name',
            schema: z.string().max(80),
        },
        {
            name: 'slug',
            schema: z.string().max(80),
        },
        {
            name: 'price',
            schema: z.int().min(0),
            description: 'In øre.',
        },
        {
            name: 'variants',
            schema: z.array(
                z.object({
                    sku: z.string().max(40),
                    label: z.string().max(60),
                    price: z.int().min(0).optional(),
                })
            ),
        },
        {
            name: 'description',
            schema: RichTextSchema,
        },
        {
            name: 'gallery',
            schema: z.array(ImageSchema).max(8),
        },
    ],
    indexes: ['slug'],
});
```

## The cart

A `carts` table, a cookie with the cart's id, and routes. The route reads the price from the CMS:

```ts title="src/routes/cart.ts"
addItem: k
    .route({
        method: 'POST',
        path: '/cart/items',
        auth: false,
        body: z.object({
            product: ProductId,
            sku: z.string().optional(),
            quantity: z.int().min(1),
        }),
        responses: {
            200: CartSchema,
        },
    })
    .handler(async ({ body, request }) => {
        const product = await kizuna.content.collections.products.get({
            id: body.product,
        });
        const variant = product.variants.find(
            (candidate) => candidate.sku === body.sku
        );
        const cart = await carts.addItem(cartIdFrom(request), {
            product: product.id,
            sku: body.sku,
            quantity: body.quantity,
            price: variant?.price ?? product.price,
        });

        return {
            status: 200,
            body: cart,
        };
    }),
```


## Checkout

The route sums the cart from the CMS's prices, creates a PaymentIntent, and writes a pending order. The page confirms it with Stripe Elements:

```ts title="src/routes/checkout.ts"
createPayment: k
    .route({
        method: 'POST',
        path: '/checkout',
        auth: false,
        body: z.object({
            email: z.email(),
            shipping: AddressSchema,
        }),
        responses: {
            200: z.object({
                clientSecret: z.string(),
            }),
        },
    })
    .handler(async ({ body, request }) => {
        const cart = await carts.get(cartIdFrom(request));
        const amount = cart.items.reduce(
            (sum, item) => sum + item.price * item.quantity,
            0
        );
        const intent = await stripe.paymentIntents.create({
            amount,
            currency: 'nok',
            metadata: {
                cart: cart.id,
            },
        });
        await orders.create({
            cart: cart.id,
            email: body.email,
            shipping: body.shipping,
            amount,
            paymentIntent: intent.id,
            status: 'pending',
        });

        return {
            status: 200,
            body: {
                clientSecret: intent.client_secret!,
            },
        };
    }),
```

## When the payment settles

```ts title="src/routes/stripe-webhook.ts"
stripeWebhook: k
    .route({
        method: 'POST',
        path: '/stripe/webhook',
        auth: false,
        hidden: true,
        body: z.unknown(),
        responses: {
            200: z.object({}),
        },
    })
    .handler(async ({ body, headers, jobs }) => {
        const event = stripe.webhooks.constructEvent(
            JSON.stringify(body),
            headers['stripe-signature']!,
            process.env.STRIPE_WEBHOOK_SECRET!
        );

        if (event.type === 'payment_intent.succeeded') {
            const order = await orders.markPaid(event.data.object.id);
            await stock.decrement(order.items);
            await jobs.sendReceipt.queue({
                input: {
                    order: order.id,
                },
            });
        }

        return {
            status: 200,
            body: {},
        };
    }),
```

## What editors change

Products, prices, variants, descriptions and galleries, as drafts until published, and every page around them:

> Put the oak desk on sale at 7 990 and feature it on the front page.

Shipping, tax and discounts are routes of yours. A shop that already runs on Medusa or Shopify keeps its products there, and a page holds them through a [relationship](/docs/cms/content/relationships).
