A site owns content and has editors. A country, a brand, a dealer, a division. Content on `cms()` belongs to every site.

| Example                                                 | Setup                                                                   |
| ------------------------------------------------------- | ----------------------------------------------------------------------- |
| A company in three countries, the same people           | No `sites`. [Localization](/docs/cms/localization)                      |
| A brand in four countries, each country its own company | [One app for every site](/docs/cms/sites/one-app)                       |
| A group with a main site and country sites              | [A group app and a countries app](/docs/cms/sites/group)                |
| A chain of forty dealers, each with a site and a domain | [Sites created by admins](/docs/cms/sites/admin-created)                |
| A partner's site that shows your offices                | [Another repository](/docs/cms/sites/shared-content#another-repository) |

## The rules

1. **A document belongs to one site, and every site under it reads it.** To share across siblings, move it up. To show it in two places, reference it.
2. **Names are unique across the tree,** so a reader resolves upward. On a site, `collections.offices` finds the shared offices. Nothing in a page names a site.
3. **An editor belongs to sites with roles, and a grant reaches everything below.** Grants add. Nothing denies.
4. **A site adds to what it inherits, never takes away.** Optional fields, a value in place of the shared one. Empty means inherited.
5. **Published reads published.** A site never shows a shared draft.
6. **Sites are addressed by id, never by URL.** Reorganise the company and no link breaks.
7. **Publishing refreshes every deployment that shows the document.**
8. **Locales are not sites.** A locale is a copy of a document, and a site names which it serves.

Every setup [shares content](/docs/cms/sites/shared-content) by these rules. A site may contain sites, for a division that owns content for several country sites, and most projects never need that level.
