---
title: defineSite()
description: 'The shape of a site that admins create in the editor.'
---

```ts
defineSite({
    fields,
});
```

When admins create sites in the editor, `defineSite` names the fields each one has beside the built-in `label`, `domains`, `icon`, `locales` and `status`, with labels for the editor. The admin who creates a site picks its key and its `domains`, and a request's domain picks the site:

```ts title="src/cms/site.ts"
export const Site = defineSite({
    fields: [
        {
            name: 'theme',
            schema: z.enum(['classic', 'bold']),
            options: {
                classic: 'Classic',
                bold: 'Bold',
            },
        },
        {
            name: 'phone',
            schema: z.string().max(30),
        },
    ],
});
```

```ts title="kizuna.config.ts"
content: cms({
    db,
    pages,
    collections: [Services],
    sites: Site,
}),
```

| Option   | Type      | Description                                                         |
| -------- | --------- | ------------------------------------------------------------------- |
| `fields` | `Field[]` | What an admin fills in for each site, as [fields](/docs/cms/fields) |

`kizuna.content.site.get()` returns the current site, with its `key` and these fields typed. The sites share one deployment, so a publish refreshes it once. Sites declared in code take [`declareSites()`](/docs/cms/reference/declare-sites) instead.

See [Sites created by admins](/docs/cms/sites#sites-created-by-admins).
