---
title: defineCollection()
description: 'Many items of one shape, each with an id type of its own.'
---

```ts
defineCollection(definition: CollectionDefinition): Collection
```

| Option                                             | Type                            | Description                                                                                                |
| -------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `name`                                             | `string`                        | How it is read: `kizuna.content.collections.<name>`                                                        |
| `id`                                               | `Kizuna.brand(...)`             | The id type its items get, shared with your routes and clients                                             |
| `fields`                                           | `Field[]`                       | What editors may change                                                                                    |
| `indexes`                                          | `string[]`                      | Fields a list may filter and sort by                                                                       |
| `immutable`                                        | `string[]`                      | Fields that never change once published, like a SKU                                                        |
| `tree`                                             | `string`                        | The field holding an item's parent. See [Trees](/docs/cms/collections#trees)                               |
| `actions`                                          | `Record<string, Action>`        | Buttons on an item. See [Actions](/docs/cms/collections#actions)                                           |
| `preview`                                          | `{ url: ({ item }) => string }` | The page the admin's Live Preview shows an item on. See [Live Preview](/docs/cms/collections#live-preview) |
| `columns`                                          | `string[]`                      | Fields the admin's list shows beside each item's title, until an editor hides them                         |
| `chooseSites`                                      | `boolean`                       | Each item picks the sites that show it. See [Articles across sites](/docs/cms/sites#articles-across-sites) |
| `label`, `group`, `requireReview`, `migrate`, `on` |                                 | As on a global                                                                                             |

`Collection.id` is the field schema a page uses to hold one item.

```ts
export const EmployeeId = Kizuna.brand('EmployeeId', z.string());

export const Employees = defineCollection({
    name: 'employees',
    id: EmployeeId,
    fields: [
        {
            name: 'name',
            schema: z.string().max(60),
        },
    ],
    indexes: ['name'],
});
```

See [Collections](/docs/cms/collections).
