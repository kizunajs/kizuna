## The page's result

A page says what its search result shows, from its own fields:

```ts title="src/app/blog/[slug]/content.ts"
export default definePage({
    name: 'articlePage',
    collection: Articles,
    metadata: {
        title: ({ content }) => content.title,
        description: ({ content }) => content.summary,
        image: ({ content }) => content.cover,
        type: 'Article',
    },
});
```

| Field         | What it is                                                      |
| ------------- | --------------------------------------------------------------- |
| `title`       | The page's own words. 30 to 60 characters show, suffix included |
| `description` | 70 to 160 characters show                                       |
| `image`       | For shared links. Falls back to the page's first image          |
| `type`        | The [structured data](#structured-data) type                    |
| `noindex`     | Keep the page out of search                                     |
| `suffix`      | `false` for a title that stands alone                           |

A page without `metadata` uses its heading, first paragraph and first image.

## The site joins the title

The separator and the site's name live on one line:

```ts title="kizuna.config.ts"
metadata: {
    title: ({ title, site }) => `${title} | ${site.name}`,
},
```

`site` is the `Site` global, so editors rename the site without a deploy. A section with its own suffix branches on `page`:

```ts
title: ({ title, site, page }) => (page === 'articlePage' ? `${title} | ${site.name} Blog` : `${title} | ${site.name}`),
```

The front page stands alone:

```ts title="src/app/(front-page)/content.ts"
metadata: {
    title: ({ content, site }) => `${site.name}: ${content.tagline}`,
    suffix: false,
},
```

## What a person writes

`MetadataSchema` is the field for pages written by hand. The editor shows it as a search result, with the function's values as placeholders and the lengths measured, suffix included:

```ts
{
    name: 'metadata',
    label: 'Search result',
    schema: MetadataSchema,
},
```

## Rendering

```tsx title="src/app/blog/[slug]/page.tsx"
export const generateMetadata = kizuna.content.pages.articlePage.metadata;
```

Title as `absolute`, description, canonical, Open Graph, Twitter and the page's other languages. Spread it to add your own.

## Structured data

```tsx title="src/app/offices/[id]/page.tsx"
<JsonLd type="LocalBusiness" of={office} />
```

| Type             | From                         |
| ---------------- | ---------------------------- |
| `Organization`   | The site global              |
| `LocalBusiness`  | An office                    |
| `Person`         | An employee                  |
| `Article`        | An article                   |
| `Event`          | An event                     |
| `JobPosting`     | A vacancy                    |
| `BreadcrumbList` | The page's place in the site |

Fields are matched by name, and the rest passed in. No `FAQPage`: Google stopped showing it in 2026.

## Redirects

A `redirects` collection, served by `nextAdapter()` at request time. Nothing redeploys.

| Field       | What it is                                            |
| ----------- | ----------------------------------------------------- |
| `from`      | The old path, unique per site                         |
| `to`        | A path, a URL, or a page or item that follows renames |
| `permanent` | `308`, or `307` for a campaign address                |

Rename-made redirects are read-only. `/offices` and `/offices/` are two addresses, as [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) says. `GET /content/redirects` lists them for anything that is not Next.

## The sitemap

```ts title="src/app/sitemap.ts"
export default async function sitemap() {
    return sitemapOf(kizuna.content, {
        siteUrl: 'https://example.co.uk',
    });
}
```

One sitemap per language under an index, `lastmod` from the last publish, `noindex` pages left out.

## Languages

The page's `metadata` writes `alternates.languages`: an absolute address per published language, the page's own, and `x-default`. Region tags are [BCP 47](https://www.rfc-editor.org/rfc/rfc5646), `en-GB`. An unpublished language is not listed.

## Images

`ImageSchema` requires alt text. The media record keeps width and height, and `?w=` serves each size for `srcset`.
