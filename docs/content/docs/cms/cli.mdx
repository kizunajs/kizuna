---
title: CLI
description: Create the tables, list the pages, and move content between environments through the routes, never a database.
---

Content is not in code, so moving it between a laptop, staging and production is a job for the CLI. `kizuna cms` extends the [kizuna CLI](/docs/cli) and exists wherever `@kizunajs/cms` is installed. Every command takes `--json` and then prints only machine-readable output, for a coding agent to drive.

## `kizuna cms migrate`

Writes `<timestamp>_kizuna_cms.sql` with the three tables into `./drizzle`, or the folder `--out` names. Run it with your other migrations.

```sh
kizuna cms migrate --out drizzle
```

## `kizuna cms pages`

Lists every page's path and name from the `content.ts` files under `src/app` or `app`, without loading the config.

```text
/contact                         contactPage
/lp/spring                       springPage
```

## Environments

`push` and `pull` call each environment's `cms` routes as a signed-in editor, so every copied draft carries a real author. Name them on the plugin:

```ts title="kizuna.config.ts"
environments: {
    local: {
        url: 'http://localhost:3000/api',
        headers: {
            authorization: `Bearer ${process.env.CMS_LOCAL_TOKEN}`,
        },
    },
    production: {
        url: 'https://example.com/api',
        headers: {
            authorization: `Bearer ${process.env.CMS_PRODUCTION_TOKEN}`,
        },
        production: true,
    },
},
```

## `kizuna cms push`

Copies one page's draft from `local`, or `--from`, into the target as a new draft, with the media it lacks. Published content on the target is never touched.

```sh
kizuna cms push springPage --to staging
```

Every branded id is checked with the brand's `exists`, and missing ids are listed rather than kept silently. The command exits `2` when any are missing.

```json
{
    "page": "springPage",
    "to": "staging",
    "version": 4,
    "mediaCopied": ["med_3f2a9c1e8b7d4a5f6c0e1d2b"],
    "missingIds": [
        {
            "brand": "ProductId",
            "id": "prod_tulips",
            "fieldPath": "featured.0"
        }
    ]
}
```

## `kizuna cms pull`

Copies every page's published content and media from the source into `local`, or `--to`, and publishes it there. It reads only from the source and refuses a destination marked `production`.

```sh
kizuna cms pull --from production
```
